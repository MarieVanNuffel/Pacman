\doxysubsection{Detailed Description}
Beheert de verschillende states van het spel. 

De \doxylink{class_state_manager}{State\+Manager} houdt een stack bij van de states (menustate, levelstate, pausestate) De bovenste state is de actieve state.

Er is 1 score zodat de score behouden blijft bij statewissels.

\doxysubsection{Detailed Description}
Beheert alle game logica. 

\doxylink{classlogic_1_1_world}{World} is de controller. Het creëert entities via de abstract factory en notificeert de observers via het Observer‑pattern. \doxylink{classlogic_1_1_world}{World} is verantwoordelijk voor\+:
\begin{DoxyItemize}
\item het spawnen en resetten van entities per level,
\item het updaten van game state per tick,
\item collision detection en pathfinding helpers voor pacman en de ghosts.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
\doxylink{classlogic_1_1_world}{World} behoort tot de logic library en bevat geen SFML‑afhankelijkheden. 
\end{DoxyNote}
